# Afloat — Privacy Policy

Effective date: 18 October 2026

Publisher: EaseMe Solutions. Contact: [EaseMe support](https://www.easeme.eu/en/contact).

This policy applies to Afloat — Floating Video, including the versions distributed through Microsoft Edge Add-ons and the Chrome Web Store.

## What Afloat does

Afloat puts an existing video into the browser's built-in Picture-in-Picture window when you click its toolbar button or use its keyboard shortcut. The video remains in its original tab.

## Information used locally

When you invoke Afloat, it accesses video elements in the current tab. It reads video readiness, playback status, video dimensions, and displayed element size to choose a video. It also checks the current Picture-in-Picture state. This is local processing of website content and video metadata, used only to provide the floating-video feature.

The extension uses an internal browser tab identifier to run this action and update its toolbar badge. It does not build or retain a record of the pages you visit. It does not read cookies, passwords, form entries, account information, or browser history, and it does not extract video source URLs or media files.

## Collection, sharing, and storage

Afloat does not send website content, video metadata, or other user data to EaseMe Solutions or any third party. It has no analytics, advertising, tracking, accounts, remote code, or network requests of its own. It does not download or record videos.

Afloat does not store user data in browser storage, synchronize data, or maintain a user database. Temporary references and event listeners exist only as needed for the current video action and floating-window status. There is no retained extension data to access, export, or delete.

We do not sell or transfer user data, use it for advertising, determine creditworthiness, or allow people to read it. Afloat's use of information is limited to providing its disclosed floating-video feature, consistent with the Chrome Web Store User Data Policy, including the Limited Use requirements, and Microsoft Edge Add-ons policies.

## Permissions and controls

- **activeTab:** temporary access to the tab you explicitly invoke Afloat on, so it can find the current video.
- **scripting:** execution of Afloat's packaged video-selection and Picture-in-Picture code in that tab.

Afloat does not request persistent access to every website. You control it through the toolbar button or keyboard shortcut. Close the floating window or click Afloat again to return the picture to its tab. You can disable or uninstall the extension through your browser at any time.

## Websites, browser stores, and support

The video website, browser provider, and extension store may process information independently under their own privacy policies. Viewing this policy on GitHub or GitHub Pages is also subject to [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). These services are not extension analytics or data recipients selected by Afloat.

If you contact EaseMe support, you choose what information to send. That separate correspondence is outside the extension's local video processing. Do not include passwords, authentication tokens, or private video links in public repository issues. For privacy questions, use the [EaseMe contact page](https://www.easeme.eu/en/contact).

## Changes

We will update this policy and its effective date if Afloat's data practices change. Changes requiring new browser permissions will also be subject to the browser's permission process.
